# Docs

This folder contains the statement documents for the three laboratory assignments of the Scientific Programming course:

- `Lab 1.docx` — Lab 1 statement (initial exploration, OOP, smoothing, derivatives)
- `Lab 2.docx` — Lab 2 statement (advanced Pandas, SNV, features, ANOVA, clustering, ML)
- `Lab 3.docx` — Lab 3 statement (modularization, O(n) complexity, optimization)

Each file describes the objectives, requirements and evaluation criteria of the corresponding lab.
