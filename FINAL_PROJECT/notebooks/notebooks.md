# Notebooks

This folder contains the Jupyter notebooks developed throughout the semester. They include the complete workflow of the project, covering:

- Data exploration
- Data preprocessing
- Computational analysis
- Detailed results and interpretations

The notebooks are organized into two subfolders:

---

## `exploration/`

Notebooks used for initial inspection and understanding of the dataset.

- **FIRST_LAB.ipynb** — Lab 1: data loading, initial visualization, first object-oriented pipeline with smoothing, normalization and derivatives.

---

## `reporting/`

Notebooks focused on final analysis and results.

- **SECOND_LAB.ipynb** — Lab 2: advanced Pandas, SNV normalization, spectral feature extraction, statistical analysis (ANOVA, Fisher), K-Means clustering and classification models (Logistic Regression, kNN).

---

> **Note on Lab 3:** this lab does not add new notebooks. The work of Lab 3 consists of reorganizing and modularizing the code from previous labs into `src/`, documenting O(n) complexity line by line, and integrating everything into an executable script (`test/test.py`).
