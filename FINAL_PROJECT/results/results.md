# Results

This folder contains all the final outputs generated by the project's full analytical pipeline, including preprocessing, spectral analysis, feature extraction, clustering, classification and statistical evaluation.

The results are organized into two subfolders:

---

## 1. `figures/`

This directory includes all graphical outputs automatically generated by `test/test.py` through the `visualization/` module. The figures summarize the main behaviors, transformations and patterns identified throughout the project.

### The folder contains:

- **spectral_raw.png / spectral_snv.png**
  MIR spectra before and after preprocessing. They allow visual verification that SNV removes baseline shifts and preserves spectral shape.

- **spectral_by_instrument.png**
  Spectra grouped by instrument in separate subplots. Useful for identifying systematically different behaviors between devices.

- **spectral_mean_by_instrument.png**
  Mean spectrum per instrument overlaid on a single axis.

- **analysis_domain_distributions.png**
  Violin + boxplot of standardized Z-score features grouped by domain (Global, Clay, Organic).

- **analysis_domain_correlation.png**
  Pearson correlation heatmap between the three domain summary indexes. (No regression line is fitted, addressing the Lab 2 feedback.)

- **analysis_fisher_ratio.png**
  Horizontal bars of Fisher Ratio per feature, ordered by discriminative power and colored by domain.

- **analysis_cluster_scores.png**
  Clustering quality metrics (Silhouette, Calinski-Harabasz, Davies-Bouldin) as a function of k.

- **analysis_separability.png**
  Scatter of the two features with highest Fisher Ratio, colored by cluster.

- **analysis_roc_curve.png**
  ROC curve of the best classification model.

- **analysis_instrument_confusion.png**
  Confusion matrix of instrument classification (5×5).

- **analysis_timing_comparison.png**
  Bar comparison of execution times between original and optimized versions of the main algorithms (SNV, moving average, global features).

---

## 2. `tables/`

This directory contains all structured numerical outputs generated during the analysis. Each CSV file corresponds to a result produced at some stage of the pipeline.

### The folder contains:

- **feature_table.csv**
  Main feature table: identifiers + 10 spectral descriptors per sample.

- **domain_summary.csv**
  Statistics (mean, std, median, min, max) of Z-scores grouped by domain.

- **domain_indexes.csv**
  Value of the three summary indexes (GlobalIdx, ClayIdx, OrganicIdx) per sample.

- **domain_correlation.csv**
  3×3 Pearson correlation matrix between domain indexes.

- **cluster_scores.csv**
  Clustering quality metrics (Silhouette, CH, DB) for k = 2..5.

- **anova_results.csv**
  Per-feature ANOVA F-test results: F-statistic, p-value, and `significant` flag (p < 0.05).

- **fisher_ratio.csv**
  Per-feature Fisher Ratio, ordered descending, with `discriminative` flag (FR > 1).

- **classification_metrics.csv**
  Metrics for the three classification models: Accuracy, Precision, Recall, F1-score, ROC-AUC.

- **instrument_confusion_matrix.csv**
  5×5 confusion matrix of instrument classification.

- **timing_comparison.csv**
  Execution times (in seconds) and speedup factor between original and optimized versions of each evaluated algorithm.

---

## Summary

The `results/` folder consolidates every numerical and graphical output generated by the complete workflow. Together, the figures and tables constitute the evidence supporting the interpretation, statistical results and final conclusions documented in the main README.
