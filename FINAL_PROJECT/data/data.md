# Data

This folder contains all the datasets used in the project, organized into two subdirectories:

---

## 1. `data/raw/`

Original dataset without preprocessing.

### `mir_soil.csv`

MIR spectral measurements of soil samples from the *Soil Spectroscopy for the Global Good (SS4GG)* dataset.

**Structure:**

| Column | Type | Description |
|---|---|---|
| `unique_id` | int | Unique identifier of the measurement |
| `instrument` | str | FTIR instrument used (INST1 – INST5) |
| `sample_id` | int | Soil sample identifier |
| `650.0` ... `4000.0` | float | MIR absorbances (1,676 wavenumbers in cm⁻¹) |

**Dimensions:** 250 rows (50 samples × 5 instruments) × 1,679 columns (3 ID + 1,676 spectral).

**Source:** SS4GG Kaggle competition — https://www.kaggle.com/competitions/ss4gg-soil-spectroscopy-validation

---

## 2. `data/processed/`

Preprocessed version of the dataset, automatically generated by running `python -m test.test`.

### `spectral_processed.csv`

Same format as `mir_soil.csv`, but with the spectra normalized via **SNV** (*Standard Normal Variate*):

$$x_{ij}^{SNV} = \frac{x_{ij} - \bar{x}_i}{s_i}$$

where $\bar{x}_i$ and $s_i$ are the mean and standard deviation of spectrum $i$.

This file is the input for statistical analysis, clustering and classification.
